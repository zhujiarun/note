## 一、C++ 程序生成过程

### 1. 课前准备

- **学习目的**：了解 C++ 从代码到程序的完整过程，有助于定位不同阶段可能出现的错误，提高调试效率。
- **语言特性**：与 Java 不同，C++ 编译过程包含多个中间步骤，每个步骤都可能产生特定类型的错误。

### 2. 设置查看后缀名

操作步骤：
1. 在文件资源管理器中选择"查看" → "选项"
2. 取消勾选"隐藏已知文件类型的扩展名"
3. 确认后即可显示完整文件名和后缀

必要性：显示文件后缀名是分析编译生成文件的基础，系统默认会隐藏常见文件类型的扩展名。

### 3. 源文件分类

#### 1) 代码文件

文件类型：
- `.h` 头文件：用于声明和引用，不直接编译
- `.cpp` 源文件：包含可执行代码，每个文件都会独立编译

编译特点：只有被引用的头文件才会参与编译过程，而每个 `.cpp` 文件都会生成对应的目标文件。

#### 2) 项目配置

配置文件类型：
- `.sln`：解决方案配置文件，可管理多个项目
- `.vcxproj`：单个项目配置文件

跨平台特性：C++ 支持多平台开发，项目配置会因开发环境（如 VS、CMake）而异。初学者建议从 VS 开始学习。

#### 3) 目标文件

- 生成规则：每个 `.cpp` 文件编译后生成一个 `.obj` 中间文件
- 文件位置：默认存储在 `x64/Debug/` 目录下
- 调试文件：`.pdb` 文件包含调试信息，建立源代码与二进制文件的对应关系

#### 4) 执行文件

- 生成过程：链接器将多个 `.obj` 文件合并生成最终的可执行文件
- 文件特征：
  - Windows 平台为 `.exe` 后缀
  - 其他平台可能无后缀名
- 执行特点：控制台程序执行后会立即退出，除非包含等待用户输入的代码
