## 相关知识点回顾

本章主要讲解 C++ 中两种常量的区别：

- **编译时常量（`constexpr`）**：在编译阶段就能确定值的常量
- **运行时常量（`const`）**：在程序运行时才确定值的常量

关键区别：编译时常量可以用于数组大小、模板参数等需要在编译期确定值的场景，而运行时常量不行。

```cpp
const int runtime_const = someFunction();  // 运行时常量
constexpr int compile_const = 42;          // 编译时常量
```
