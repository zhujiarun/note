## 一、注释和 cout

### 1. cout 输出原理

- **缓冲机制**：cout 输出采用缓冲区设计，不会立即显示在控制台，而是积累到一定量才刷新显示，目的是提高效率（减少硬件交互次数）
- **刷新条件**：
  1. 缓冲区满时自动刷新
  2. 程序主动调用 `endl` 或 `flush` 强制刷新
- **多线程影响**：在循环或多线程场景中可能出现输出延迟现象，需特别注意缓冲区控制

### 2. C++ 注释

#### 1) 多行注释

- **格式**：使用 `/* */` 开头和结尾的注释块
- **应用场景**：适合大段代码说明、文件头描述或复杂逻辑解释
- **预处理机制**：编译器在预处理阶段会删除所有注释内容（包括空行）

```cpp
/*
 * 这是一个多行注释
 * 可以跨越多行
 */
```

#### 2) 单行注释

- **格式**：以 `//` 开头，仅注释当前行内容
- **优势**：操作简便（只需添加两个斜杠），适合临时禁用代码或简短说明
- **规范建议**：每行代码都应添加解释其功能的单行注释

```cpp
// 这是一个单行注释
int x{100};  // 初始化变量 x 为 100
```

#### 3) 应用案例

开发规范：
- 每个文件开头应添加功能说明注释
- 实现复杂逻辑前先写注释描述设计思路
- 阅读他人代码时应补充理解性注释

教学意义：通过注释培养"先设计后编码"的开发习惯。

### 3. cout 输出使用

#### 1) 支持多种格式多个数据合并输出

- **管道式语法**：使用 `<<` 运算符链式输出，如 `cout << "字符串" << 200`
- **类型安全**：相比 C 语言的 `printf`，cout 会进行类型检查，避免格式错误
- **混合输出**：支持字符串、数字等多种数据类型连续输出（示例中演示了中英文混合输出）

```cpp
cout << "Hello World" << "\n";
cout << "字符串一" << 200 << endl;
```

#### 2) 换行并刷新缓冲区

- `endl` 作用：1) 插入换行符 2) 强制刷新输出缓冲区
- 替代方案：仅刷新不换行可使用 `flush` 方法
- 命名空间：`endl` 实际是 `std::endl`，属于标准库命名空间

#### 3) 简化命名空间

```cpp
using namespace std;
// 声明后可直接使用 cout 等标准库组件
```

- 语法：`using namespace std;` 声明后可直接使用 `cout` 等标准库组件
- 设计原理：命名空间解决多库命名冲突问题，using 声明是可控的简化方案
- 冲突处理：出现命名冲突时可取消 using 声明，改用 `std::` 前缀
