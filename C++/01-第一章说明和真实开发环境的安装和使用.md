## 一、开发环境的安装和使用

### 1. 选择工具

- **专业推荐**：建议优先使用 Visual Studio（VS）作为 C++ 开发工具，因其在企业培训中使用最广泛
- **版本要求**：至少支持 C++14 特性，新版本可兼容开发旧版本程序
- **学习价值**：通过第一个简单程序理解程序生成过程，这对 C++ 程序员至关重要

### 2. 安装环境

#### 1) 官网下载

- 安装方式：支持在线安装或使用课程提供的安装包
- 硬件要求：需要 4-5GB 磁盘空间，确保电脑有稳定网络连接

#### 2) 选择 C++ 环境

- 关键组件：必须勾选"使用 C++ 的桌面开发"选项
- 空间需求：完整安装约需 10.19GB 空间
- 安装提醒：初学者只需安装 C++ 开发环境，其他组件可暂不安装

#### 3) 更改位置

- 路径建议：可更改安装位置到 D 盘以减少 C 盘压力
- 注意事项：安装路径不要包含中文或特殊字符

### 3. 启动程序

#### 1) 登录注册

- 登录跳过：可选择"暂时跳过此项"不进行账号注册
- 主题推荐：建议选择深色主题以减轻长时间编程的视觉疲劳

### 4. 打开项目

- 入口方式：可通过开始菜单或搜索 Visual Studio 启动
- 环境验证：若找不到 C++ 项目模板，需返回检查 C++ 组件是否安装完整

### 5. 创建项目

#### 1) 创建新项目

- 模板选择：选择"C++ Windows 控制台"项目模板
- 常见问题：若无此选项说明 C++ 环境未正确安装

#### 2) 配置新项目

- **位置选择**
  - 路径规范：避免使用中文路径，建议在 D 盘创建专用代码目录
  - 目录结构：保持简洁，便于后续项目管理
- **项目文件和解决方案的名称**
  - 命名规范：全部使用小写字母命名，确保跨平台兼容性
  - 关系说明：一个解决方案可包含多个项目，初学者建议一对一关系
- **将解决方案和项目放在同一目录中**
  - 目录优化：勾选此选项可简化目录结构
  - 工程实践：符合现代 C++ 项目组织方式

#### 3) 查看项目配置

- 默认配置：创建后保持默认设置不变
- 界面布局：左侧为解决方案资源管理器，右侧为代码编辑区

#### 4) 执行程序

- 运行验证：点击绿色三角形按钮执行程序
- 成功标志：显示 "Hello World" 表示环境配置成功
- 调试方式：F5 启动调试，Ctrl+F5 直接运行不调试
