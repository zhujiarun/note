## 一、代码到程序生成过程

### 1. 过程

完整流程：**预处理 → 编译 → 汇编 → 链接 → 执行**，每个步骤都可能产生特定错误。

#### 1) 预处理

- **核心功能**：主要处理 `#include` 指令，将依赖文件全部复制到当前文件
- **典型错误**：找不到包含文件时会产生复制错误
- **处理范围**：批量处理所有预处理指令，但本课程重点讲解文件包含操作

#### 2) 编译

- **核心任务**：将单个 `.cpp` 文件转换为目标系统的汇编代码（生成 `.s` 文件）
- **错误类型**：所有语法错误都在此阶段被发现
- **重要特性**：
  - 每个 `.cpp` 文件独立编译，互不影响
  - 不同 `.cpp` 文件中重复定义在编译阶段不会报错（链接阶段才会暴露）
- **输出产物**：汇编码（机器指令因系统而异）

#### 3) 汇编

- **实质操作**：将汇编代码编译为机器指令
- **输出文件**：
  - Windows 系统生成 `.obj` 文件
  - Linux/Android/HarmonyOS 系统生成 `.o` 文件
- **开发者视角**：通常将编译和汇编视为一个整体过程

#### 4) 链接

两大功能：
- 合并多个 `.obj`/`.o` 文件
- 设置程序入口（如查找 `main` 函数）

典型错误：
- 函数声明但未实现
- 多个 `main` 函数冲突
- 重复定义（编译通过但链接失败）

依赖处理：包含所需库文件的链接

#### 5) 执行

- 运行环境：Windows 中双击 `.exe` 执行
- 动态加载：运行时才加载系统动态库
- 错误类型：
  - 内存溢出
  - 数组越界
  - 动态库加载失败
- 关键特征：某些错误只能在运行时暴露

### 2. 内容总结

- **预处理**：文件包含和宏替换（重点处理 `#include`）
- **编译 + 汇编**：代码 → 汇编 → 机器码（`.cpp` → `.s` → `.obj`/`.o`）
- **链接**：合并目标文件 + 解析引用（处理跨文件依赖）
- **执行**：动态加载 + 运行时检查（最终用户接触阶段）
- **排错价值**：明确各阶段可能出现的错误类型，提高调试效率
