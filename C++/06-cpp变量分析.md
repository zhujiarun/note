## 一、变量分析

### 1. 什么是变量

- **本质特征**：变量是存储在内存中可变化的数据量，区别于常量（不可变化的数据量）
- **存储机制**：必须存储在内存中才能实现值的修改，直接写在代码中的数值无法被程序运行时修改

核心要素：
- **变量名**：用于标识和访问变量的名称
- **内存大小**：决定变量能存储的数据范围
- **内容类型**：限定变量存储的数据种类（如整数、浮点数等）
- **操作限定**：定义变量支持的计算方法（如加减乘除等）

### 2. 变量定义语法

标准格式（C++11 后推荐语法）：

```cpp
int x{100};
```

- `int`：变量类型
- `x`：变量名称
- `{100}`：初始化值

语法优势：相比旧式 `x = 100` 语法，新语法有更严格的类型检查，能防止类型不匹配的错误（如整数变量赋字符串值）。

### 3. 语句包含的内容

#### 1) 类型

基础类型分类：
- **整数类型**：`int`（无小数点数字）
- **浮点类型**：`float` / `double`（含小数点数字）
- **字符类型**：`char`（单个字符）
- **布尔类型**：`bool`（逻辑值）

类型作用：
- 定义变量存储的数据性质
- 决定变量支持的操作方法
- 影响变量的内存占用大小

#### 2) 内存大小

基本单位：1 字节 = 8 位二进制

| 类型 | 内存占用 |
|------|----------|
| `bool` | 1 字节 |
| `char` | 1 字节 |
| `int` | 4 字节 |
| `long long` | 8 字节 |
| `float` | 4 字节 |
| `double` | 8 字节 |

特殊说明：
- `char` 可表示 ASCII 字符或小整数（-127~127）
- `int` 最大约 21 亿（2³¹）
- `long long` 最大约 2⁶³，适合大数值场景

查看方法：使用 `sizeof` 运算符获取类型/变量内存大小

```cpp
sizeof(int)  // 返回 4
```

#### 3) 运算方法

主要运算符：
- 算术运算：`+` `-` `*` `/` `%`（加减乘除模除）
- 自增自减：`++` `--`
- 复合赋值：`+=` `-=` `*=` `/=` `%=`

运算优先级：
- 不建议记忆复杂优先级规则
- 使用括号明确运算顺序（如 `(a + b) * c`）

类型特性：
- 不同数据类型支持不同运算（如字符串不支持乘除）
- 浮点数运算精度与整数运算存在差异

#### 4) 对象

内存关联：
- 变量名指向实际的内存空间
- 所有变量都占用栈内存空间

地址获取：
- 使用 `&` 运算符获取变量地址（如 `&x`）
- 地址值表示变量在内存中的位置

命名规则：
- 可由字母、数字、下划线组成
- 不能以数字开头
- 区分大小写
- 支持中文变量名（但不推荐）
