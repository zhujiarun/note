## 一、第一个 C++ 程序分析

程序结构：总共不到十行代码，分为三块内容：`#include <iostream>`、`int main()` 和 `std::cout` 输出语句。

### 1. `#include <iostream>`

- **功能**：将 iostream 文件复制到当前位置
- **位置**：通常放在程序文件顶部

#### 1) 预处理复制文件内容

- 预处理特性：以 `#` 开头的代码是预处理指令，在编译前执行
- 执行时机：不属于 C++ 语法代码，在程序执行前处理
- 工作方式：相当于人工复制文件操作，包含三个部分：`include` 关键字、尖括号和文件名

#### 2) 环境中自带的文件

- 尖括号含义：表示从 IDE 配置的系统库路径查找文件
- 自定义文件：引用用户自定义文件时不使用尖括号
- 库文件来源：系统自带或环境配置好的库文件

#### 3) iostream 头文件

- 名称含义：IO 表示输入输出（input/output），stream 表示流
- 功能：提供控制台程序的输入输出功能
- 流概念：像管道一样传输数据，输入流接收键盘输入，输出流显示到屏幕
- 实际文件：具体对应名为 `iostream` 的文件

### 2. `int main()`

#### 1) 程序入口函数

- 入口点：程序执行的起始位置，必须唯一
- 命名要求：`main` 是固定函数名，整个程序只能出现一次
- 返回值：`int` 表示返回整数类型，目前作为固定格式
- 参数：空括号表示不接收参数

```cpp
int main() {
    // 程序代码写在这里
}
```

- 大括号作用：界定函数代码块范围，包含内存控制区域
- 执行范围：程序主要代码都写在大括号内
- 格式要求：C++ 用大括号而非缩进或换行界定代码块

### 3. `std::cout`

#### 1) 控制台对象

- 来源：来自 iostream 头文件中定义的控制台对象
- 命名空间：`std::` 表示标准命名空间，必须加此前缀
- 流操作符：`<<` 符号像箭头，表示数据流向控制台
- 字符串格式：用双引号包裹文字内容，`\n` 表示换行符
- 分号作用：明确表示语句结束，不同于 Python 等用换行结束
- 格式要求：必须使用英文分号
- 空白处理：编译时会删除代码中多余的空格和换行

| `int main()` 函数 | 程序唯一入口点，大括号 `{}` 定义代码块范围。`int` 为返回值类型（固定格式），函数名 `main` 不可重复。 | 考试重点：入口函数的必要性（多文件程序执行起点）；大括号的作用（代码块与内存控制区域）。 | ⭐⭐ |
| `std::cout` 与流操作符 `<<` | `cout` 为控制台输出对象（来自 iostream），`<<` 表示数据流向（向左传递）。`std` 为命名空间，避免命名冲突。 | 易混淆点：`<<` 操作符的方向性（数据流向对象）；`std::` 前缀的省略方法（`using namespace std`）。 | ⭐⭐⭐ |
| 字符串与转义字符 | 双引号包裹的文本（如 `"Hello World"`），`\n` 为转义字符表示换行。分号 `;` 标记语句结束（非换行符）。 | 考试重点：转义字符的使用（如 `\t` 制表符）；分号缺失导致的语法错误。 | ⭐⭐⭐ |
