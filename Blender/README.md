# 下半球纹理到圆盘平面的投影脚本

将全景纹理（Equirectangular）的下半球部分映射到一个平面圆盘上。

## 三种投影方式

| 脚本 | 投影方式 | 特点 |
|------|---------|------|
| `hemisphere_to_disk_lambert.py` | Lambert等面积投影 | 保持面积比例，纹理分布均匀 |
| `hemisphere_to_disk_equidistant.py` | 等距方位投影 | 保持径向距离比例，简单直观 |
| `hemisphere_to_disk_stereographic.py` | 立体投影（保角） | 保持局部形状和角度不变形 |

## 使用方法

1. 在Blender中打开 **Scripting** 工作区
2. 打开任一脚本文件
3. 修改脚本顶部的 `TEXTURE_PATH` 为你的全景纹理图片路径
4. 点击运行

## 参数说明

每个脚本顶部都有以下可调参数：

- `TEXTURE_PATH`: 全景纹理路径（支持相对路径 `//` 或绝对路径）
- `DISK_RADIUS`: 圆盘半径，默认 1.0
- `DISK_SEGMENTS`: 圆盘圆周方向细分数，默认 128
- `DISK_RINGS`: 圆盘径向环数，默认 64

## 投影原理

给定圆盘上一点的极坐标 (r, α)，通过不同的投影公式反算出对应的球面坐标 (θ, φ)，
然后将球面坐标转换为equirectangular纹理的UV坐标进行采样。

### Lambert等面积
```
r = √(1 - cos|φ|)
```
反算：`|φ| = arccos(1 - r²)`

### 等距方位
```
r = |φ| / (π/2)
```
反算：`|φ| = r × π/2`

### 立体投影（从南极投影）
```
r = cos(φ) / (1 + sin|φ|)
```
反算：`|φ| = 2 × arctan((1-r)/(1+r))`

其中 |φ| 为从赤道到南极的角度 [0, π/2]。
